## 🚀 Sobre a FluidZap

A **FluidZap** é uma plataforma inovadora que transforma o atendimento no WhatsApp de pequenas e médias empresas. Diferente de chatbots tradicionais engessados (com menus "Digite 1 para X"), nossa IA utiliza **RAG (Retrieval-Augmented Generation)** para ler os documentos, PDFs, catálogos e cardápios da sua empresa, aprendendo instantaneamente como um funcionário real.

### Nossa Missão
> *Automatizar o que é repetitivo, para que humanos foquem no que exige empatia.*

1. **Conexão Simples:** Escaneie o QR Code via API Oficial (sem risco de banimento).
2. **Treinamento Fluido:** Faça upload dos seus dados, a IA entende o contexto sozinha.
3. **Atendimento 24/7:** A IA responde os clientes como um humano.
4. **Handoff Perfeito:** Assuma a conversa manualmente a qualquer momento pelo nosso painel.
